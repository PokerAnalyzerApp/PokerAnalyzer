## 🇬🇧 English

### What is PokerAnalyzer?

PokerAnalyzer is a free poker analysis tool developed to make poker study more accessible.

It combines hand analysis tools with artificial intelligence capabilities through Google Gemini, helping players review their decisions and learn from their gameplay.

### Features

- ♠️ Poker hand analysis.
- 🤖 AI-powered recommendations using Google Gemini.
- 🧠 Multiple Gemini model options.
- 📊 Hand history review.
- 📁 Excel export.
- ⚙️ Customizable Gemini configuration.

### Download and Installation

1. Open the **Releases** section of this repository.
2. Download the latest `PokerAnalyzer_Setup.exe` installer.
3. Run the installer.
4. Follow the installation instructions.
5. Open PokerAnalyzer.

**Download:** See the latest release in the Releases section.

### Google Gemini Configuration

To use AI-powered analysis:

1. Obtain your own Google Gemini API key.
2. Open PokerAnalyzer.
3. Select the Gemini configuration option.
4. Enter your API key.
5. Select your preferred Gemini model.
6. Save your settings.

Your API key is stored locally using Windows Credential Manager.

Please keep your API key private. Google may apply usage limits or charges depending on your account and API plan.
